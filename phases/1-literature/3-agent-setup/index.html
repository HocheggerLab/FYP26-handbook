    Part 3 · Getting ready to use the agents¶

    Goal¶

    Open a project folder in VS Code and run a small Python script with uv. You do not need to have taken the Python course.

    This is preparation for Part 3's agent runs, not an extra evaluation task. VS Code is your editor; the terminal runs commands; uv manages Python and project environments. Claude Code is introduced separately on 10 November.

    Time¶

    Try the setup before 3 November. Bring your laptop and any errors to that session; we will work through folders, terminals, Python and uv together. If you get stuck, stop rather than spending hours trying different installers.

    Agent access starts on 10 November. Evaluation runs start only after the independent references are assembled and locked on 17 November. See the project schedule.

    Before you start¶

    • Use a laptop on which you are allowed to install software. Ask university IT for help with a managed device; do not bypass its restrictions.
    • Keep your assigned abstracts and answers safe. This exercise uses a new practice folder, not the evaluation papers.
    • You do not need Anaconda, Docker, Homebrew or the full Xcode application for this exercise. Do not uninstall an existing Python setup.

    Steps¶

    1. Install VS Code¶

    Download Visual Studio Code for your operating system and install it. Open Extensions, search for Python, and install the extension published by Microsoft (ms-python.python). No paid AI extension is needed.

    2. Install uv¶

    Use the official uv installation instructions. The commands below download and run Astral's installer; the official page also explains how to inspect the script first. Run commands in a normal terminal, not an administrator terminal.

    Open Terminal and run:

    curl -LsSf https://astral.sh/uv/install.sh | sh

    Open PowerShell and run the official installer:

    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

    This permits the installer script for that process; it is not an instruction to weaken a managed computer's policy. If installation is blocked, stop and bring the error to the session or university IT.

    Open your terminal and run:

    curl -LsSf https://astral.sh/uv/install.sh | sh

    Close and reopen VS Code after installation so it picks up the new command.

    Mac users: no full Xcode download

    uv's standalone installer and this Python exercise do not need the full Apple developer suite. If Git or a later package needs Apple's developer tools, the smaller Command Line Tools for Xcode are usually sufficient:

    xcode-select --install

    Do not install these pre-emptively for this exercise. If prompted for administrator approval, handle that yourself or ask IT—not through an agent.

    3. Open a practice folder and terminal¶

    Create an empty folder called fyp26-practice using Finder or File Explorer. In VS Code choose File → Open Folder, select it, then choose Terminal → New Terminal. Run each command separately:

    uv --version
uv python install 3.12
uv venv --python 3.12

    The first command should print a version. The next commands install Python 3.12 for this practice and create a local .venv environment. You do not need to install Python separately or activate the environment manually. Later course projects may specify their own Python version and dependencies.

    4. Run one script¶

    In VS Code, create hello.py inside fyp26-practice, enter the following and save the file:

    import sys

print("FYP26 setup works")
print("Python:", sys.version.split()[0])
print("Interpreter:", sys.executable)

    In the integrated terminal run:

    uv run --python 3.12 hello.py

    You should see FYP26 setup works, a Python version and the interpreter path. The interpreter should be inside your practice folder's .venv.

    Open the VS Code command palette (Cmd+Shift+P on Mac, Ctrl+Shift+P on Windows/Linux), choose Python: Select Interpreter, and select the .venv interpreter. For now, use the terminal command above to run scripts rather than installing additional code-runner extensions.

    Done when¶

    • VS Code opens your fyp26-practice folder.
    • uv --version prints a version.
    • uv run --python 3.12 hello.py prints the success message.
    • You can find the script and terminal output, and select the .venv interpreter.

    No submission is required. Bring the working setup—or the exact error—to 3 November. We will practise reading inputs, running commands and finding outputs together. You are not expected to learn Python in advance.

    If you get stuck¶

    Problem Try this
    uv is not recognised Fully close and reopen VS Code. If it still fails, keep the installer output for the session.
    Python cannot find hello.py Open the practice folder in VS Code; check that the file is saved there as hello.py, not hello.py.txt.
    The wrong Python is selected Use Python: Select Interpreter and choose the practice folder's .venv.
    Downloads are blocked or installation needs permissions Stop and contact IT or bring the error. Do not disable security controls.
    A command fails Copy the command and error, without passwords or tokens. Do not run a series of unrelated fixes from the internet.

    Setup is not permission to use AI on your reference papers

    The 50 abstracts remain independent until submitted and locked. The three full-text papers prepared during 10–17 November also remain independent, even after you receive agent access. Do not send these papers or your draft answers to an agent for interpretation or checking. See Your Claude account.
